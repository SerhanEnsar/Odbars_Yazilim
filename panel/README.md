# 🎛️ ODBARS GCS Panel

The Ground Control Station interface for the ODBARS autonomous UAV system. Built with React + Vite, packaged as a desktop app via Electron.

## Features

- Real-time telemetry and status display
- Camera feed integration
- Mission control dashboard
- Offline-capable desktop application

## Tech Stack

- React 18 + Vite
- Electron (desktop packaging)
- Lucide Icons
- Custom CSS

## Development

```bash
npm install
npm run dev          # Vite dev server (browser)
npm run electron     # Launch Electron app
npm run build        # Production build
```

## Project Context

This panel is part of the [ODBARS](https://github.com/serhanensar/Odbars_Yazilim) software suite for TEKNOFEST 2026 AI in Aviation.
